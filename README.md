# Quantum-Engine
Quantum Engine — лёгкий графический браузер на C++ с встроенным WebView2-движком. Вкладки, навигация, адресная строка, тёмная тема. Минимальные зависимости, статическая сборка, один exe-файл. Быстрый и приватный — без телеметрии и аналитики. Работает на Windows 10/11. Идеален как основа для кастомных браузеров и встраиваемых решений.
