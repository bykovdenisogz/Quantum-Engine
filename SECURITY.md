# Privacy Policy — Quantum Engine

**Последнее обновление:** 5 июня 2026 г.

## 1. Общие положения

Quantum Engine — это локальное программное обеспечение, работающее исключительно на вашем устройстве. Данный браузер не собирает, не хранит и не передаёт какие-либо данные пользователя третьим лицам.

## 2. Сбор данных

**Quantum Engine не собирает никаких персональных данных.**

- Не используются файлы cookie для отслеживания
- Не собирается история посещений на сторонних серверах
- Не передаются данные о поведении пользователя
- Не установлено никаких систем аналитики или телеметрии

## 3. Сетевая активность

Браузер устанавливает сетевые соединения только для загрузки веб-страниц, которые вы запрашиваете. Все запросы направляются непосредственно на запрашиваемые вами сайты. Quantum Engine не перенаправляет и не анализирует ваш трафик.

## 4. Хранение данных

Вся информация (история, настройки вкладок) хранится локально в оперативной памяти вашего устройства. При закрытии приложения данные не сохраняются на диск, если иное не реализовано в функционале приложения.

## 5. Третьи лица

Quantum Engine не взаимодействует с третьими сторонами в целях сбора данных. Единственная внешняя зависимость — WebView2 Runtime, поставляемый Microsoft и используемый для рендеринга веб-страниц в соответствии со стандартами браузерного движка.

## 6. Безопасность

Проект использует стандартные механизмы безопасности операционной системы. Исходный код открыт и доступен для аудита.

## 7. Изменения в политике

Все изменения в данной политике публикуются в репозитории проекта и вступают в силу с момента публикации.

## 8. Контакты

По вопросам конфиденциальности создайте Issue в репозитории проекта на GitHub.
